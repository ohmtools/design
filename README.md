# ohmtools design

> **Note:** This project was mostly generated by AI: code, configuration and
> documentation were written with [Claude Code](https://claude.com/claude-code).

One look for every ohmtools app, web page and document: shadcn/ui `base-sera`
with the Red theme on Neutral, Inter, square corners, no boxes, red as the only
accent, light and dark following the device. The rules are in
[DESIGN.md](DESIGN.md), the values in [`tokens/`](tokens/) (Design Tokens
format, colours in OKLCH); everything else is generated from them. Reference
implementation: [zeiteisen](https://github.com/ohmtools/zeiteisen).

| Path | What |
| --- | --- |
| [`DESIGN.md`](DESIGN.md) | The rules, and every colour as a table |
| [`tokens/`](tokens/) | Source of every value ([DTCG](https://www.designtokens.org) JSON) |
| [`shadcn/components.json`](shadcn/components.json) | shadcn config |
| [`shadcn/index.css`](shadcn/index.css) | `src/index.css` of a shadcn app (generated) |
| [`dist/tokens.css`](dist/tokens.css) | CSS custom properties for pages without shadcn (generated) |
| [`dist/tokens.json`](dist/tokens.json) | Every colour per mode as `oklch()` and hex, for anything else (generated) |
| [`dist/ohmtools-colors.sty`](dist/ohmtools-colors.sty) | The colours for LaTeX (generated) |
| [`assets/app-icon.svg`](assets/app-icon.svg) | App icon template |
| [`examples/index.html`](examples/index.html) | The look rebuilt on `dist/tokens.css` alone |

## Using it

### shadcn app (React, Tailwind v4)

1. Set the project up as shadcn's [Vite guide](https://ui.shadcn.com/docs/installation/vite)
   says, then replace `components.json` and `src/index.css` with
   [`shadcn/components.json`](shadcn/components.json) and
   [`shadcn/index.css`](shadcn/index.css). App-specific CSS goes at the end of
   `src/index.css`.
2. Add components with `npx shadcn@latest add <name>` and strip `uppercase`
   and `tracking-wider` / `tracking-widest` from what it writes.
3. Dark mode: `public/dark.js` and a `ThemeProvider`, see DESIGN.md, "Light
   and dark". No theme toggle.
4. Check in CI that the theme stays as it is:

   ```yaml
   - run: npx --yes github:ohmtools/design check src/index.css components.json src/components/ui/*.tsx
   ```

### Web page without shadcn

Copy [`dist/tokens.css`](dist/tokens.css) into the project, use only its
custom properties (`var(--primary)`), and rebuild the controls the way
[`examples/index.html`](examples/index.html) does. `ohmtools-design check`
takes the copy and the page's own CSS too.

### LaTeX

Copy [`dist/ohmtools-colors.sty`](dist/ohmtools-colors.sty) next to the `.tex`
file, `\usepackage{ohmtools-colors}`, then use the names: `ohm` plus the token
in PascalCase (`primary` → `ohmPrimary`, `muted-foreground` →
`ohmMutedForeground`, `chart-1` → `ohmChart1`). Paper is light, so these are
the light values.

### Anything else

[`dist/tokens.json`](dist/tokens.json) has every colour per mode as `oklch()`
and sRGB hex, the font and the spacing, plus what each colour is for.

### Claude Code

Add to the project's `CLAUDE.md`:

```md
## Design

Follows the ohmtools design: https://github.com/ohmtools/design, rules in its
DESIGN.md (shadcn base-sera, Red on Neutral, Inter; no uppercase, no boxes, no
theme toggle). Colours only through its tokens. Read DESIGN.md before any
visible change; a rule that should change is changed there first, for every
app.
```

## The check

`npx --yes github:ohmtools/design check <file>…`, from the project's root,
exits 1 when a file does not follow the design:

- a CSS file that declares `--primary` must carry every theme colour, the
  radius and the font unchanged, light (`:root`) and dark (`.dark`, or `:root`
  in a `prefers-color-scheme: dark` media query); app-specific variables are
  fine;
- `components.json` must use the same style, base colour, icons and menu
  settings;
- no file may set uppercase text or wide letter spacing (Tailwind classes,
  `text-transform`, `\MakeUppercase`).

Pin a tag or commit (`github:ohmtools/design#<ref>`) for reproducible CI.

## Changing the design

A change here is a change for every app. Edit `tokens/` or `DESIGN.md`, then:

```sh
npm run build   # regenerate shadcn/index.css, dist/ and the table in DESIGN.md
npm test        # node:test
npm run check   # fails if a generated file is out of date (CI runs it)
```

Node 22 or newer, no dependencies. Commit the generated files with the change;
each app then takes them over, and its check shows what is left.
